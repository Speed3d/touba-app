# مجلد `.claude` — إعدادات عمل طوبة مع Claude

بنية مساعِدة لتسهيل العمل وضبط الجودة. الملفات هنا تُكمّل دليل المشروع الرئيسي [`../CLAUDE.md`](../CLAUDE.md) (الذي يُحمَّل تلقائياً كل جلسة).

```
.claude/
├── settings.json          إعدادات وصلاحيات مشتركة (allow/deny/ask للأوامر)
├── settings.local.json    إعدادات محلية لكل مطوّر (لا تُرفع — في .gitignore)
├── rules/                 قواعد مُلزِمة يرجع إليها CLAUDE.md
│   ├── 01-cost-rationing.md     ترشيد الاستهلاك
│   ├── 02-security-invariants.md ثوابت الأمان (حقول CF-only)
│   └── 03-conventions.md         اصطلاحات الكود
├── commands/              أوامر مختصرة (slash commands)
│   └── deploy.md          /deploy — نشر Firebase
└── cache/                 كاش/مخرجات مؤقتة (لا تُرفع)
```

## ملاحظة عن موقع CLAUDE.md
الدليل الرئيسي موضوع في **جذر المشروع** (`../CLAUDE.md`) لأن Claude Code يحمّله من هناك تلقائياً كل جلسة. ملفات `.claude/rules/` تُقرأ عند الإشارة إليها من الدليل أو عند الحاجة.

## المراجع الحيّة (مصدر الحقيقة لحالة المشروع)
- `docs/تحليل_المشروع_الشامل.md` — الحالة الفعلية + الأخطاء + خطة الإصلاح.
- `docs/تصميم_الأساس.md` — المخطط الهندسي المعتمد.
- `docs/دليل_النشر.md` — خطوات النشر على `touba-3ds`.
