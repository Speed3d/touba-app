## المسار (أ) — 🔑 ملف الحالة المشترك «الذاكرة عبر الأجهزة»

**المشكلة:** ذاكرة Claude تعيش في `C:\Users\...\.claude\projects\D--football\memory\` — **لا تُرفع مع git** → على الماك يبدأ بلا سياق.

**العمل:**
1. **`docs/الحالة_الحالية.md`** (جديد) — صفحة واحدة تُقرأ في كل جلسة، تحوي:
   - الثوابت التقنية والممنوعات (مختصرة).
   - **أين وصلنا** + آخر وجبة منجزة + المنشور مقابل ما ينتظر النشر.
   - **الخطوة التالية المتّفق عليها**.
   - نتائج آخر فحص (`analyze` / `test` / `eslint`).
   - تاريخ آخر تحديث + **الجهاز** الذي حدّثه (ويندوز/ماك).
2. **ربط إلزامي في `CLAUDE.md`:** «اقرأ `docs/الحالة_الحالية.md` **أولاً** في كل جلسة، وحدّثه **قبل كل commit**».
3. **أمر `/handoff`** (`.claude/commands/handoff.md`) — يفحص (analyze + test + git status + المعلّق للنشر) ثم يعيد كتابة ملف الحالة، فيبقى صادقاً دائماً.
4. **نقل خلاصة الذاكرة الحالية** إلى الملف مرّة واحدة (حفظ الخبرة المتراكمة).

## المسار (ب) — 📦 `craftsman_backup` → submodule

**الوضع المُتحقَّق منه:**
- مستودع git مضمّن، ريموته `github.com/Speed3d/test_app.git`.
- الالتزام المسجّل في طوبة: `6e52113` ✅ موجود على الريموت.
- الالتزام المحلي الحالي: `5be3597` ✅ موجود على الريموت أيضاً (**أحدث بـ 25 التزاماً**).
- بلا `.gitmodules` → على الماك يصل **مجلداً فارغاً**.

**العمل:**
1. إنشاء **`.gitmodules`** يربط `craftsman_backup` بالرابط أعلاه.
2. تحديث المؤشّر المسجّل إلى **`5be3597`** ليصل للماك أحدث نسخة من المرجع.

> ### ⚠️ توضيح مهم — لن نعدّل «حرفي العراق» إطلاقاً
> تحديث المؤشّر يعني: **مستودع طوبة يسجّل «أيّ نسخة من حرفي يجب جلبها»**. لا كتابة ولا حذف ولا إضافة داخل `craftsman_backup/` — محتواه يبقى كما هو حرفياً. هو مرجع للقراءة فقط، وسيبقى كذلك.

3. على الماك: `git submodule update --init --recursive` → يصل المرجع كاملاً.

## المسار (هـ) — 🍎 دليل الماك + قائمة تحقّق Firebase

**`docs/دليل_الإعداد_على_الماك.md`** (جديد):
- Xcode + Command Line Tools + قبول الرخصة.
- CocoaPods على Apple Silicon (M5) + `pod install` داخل `ios/`.
- Flutter SDK + `flutter doctor`.
- محاكي iPhone + محاكي أندرويد.
- `firebase login` + `firebase use touba-3ds`.
- **تسلسل الاستئناف اليومي:** `git pull` → `git submodule update --init` → `flutter pub get` → فتح المحادثة.

**قائمة تحقّق Firebase (تُنفَّذ من الماك في أول جلسة هناك):**

| # | التحقّق | إن كان ناقصاً |
|---|---|---|
| 1 | `android/app/google-services.json` موجود | نسخه يدوياً من ويندوز |
| 2 | `ios/Runner/GoogleService-Info.plist` موجود | نسخه + التأكد من إضافته لهدف Xcode |
| 3 | `firebase.json` + `.firebaserc` موجودان | نسخهما (`.firebaserc` يجب أن يشير لـ `touba-3ds`) |
| 4 | `flutter build apk --debug` ينجح | معالجة ما يظهر |
| 5 | `flutter build ios --debug --no-codesign` ينجح | معالجة ما يظهر |

> **صراحة:** لا أستطيع اختبار الماك من هنا. الخطة تجهّز وتوثّق كل شيء، وأنت تنفّذ خطوات الماك وتخبرني بأي خطأ فأصلحه فوراً.
