# 🚀 دليل النشر — منصة «طوبة» (مشروع `touba-3ds`)

> مرجع عملي لنشر قواعد الأمان والفهارس والتخزين والدوال السحابية على Firebase.
> يُنفَّذ من **جذر المشروع** `D:\football`. مستند حيّ — حدّثه عند تغيّر الإجراءات.

---

## 1. المتطلبات
- **Firebase CLI** مثبّت (`firebase --version`).
- تسجيل دخول: `firebase login`.
- المشروع الافتراضي = `touba-3ds` (مضبوط في `.firebaserc`).
- **خطة Blaze** مطلوبة **للدوال السحابية فقط** (القواعد/الفهارس/التخزين تعمل على المجانية).

---

## 2. الأوامر الأساسية

```bash
# (مرة واحدة) تسجيل الدخول واختيار المشروع
firebase login
firebase use touba-3ds

# نشر قواعد الأمان + الفهارس + التخزين (خطة مجانية كافية)
firebase deploy --only firestore:rules,firestore:indexes,storage

# نشر الدوال السحابية (يتطلّب خطة Blaze)
cd functions
npm install
cd ..
firebase deploy --only functions
```

> 🔎 الفهارس تُبنى في الخلفية وقد تأخذ بضع دقائق — هذا طبيعي.

## 3. استكشاف الأخطاء وحلّها (Troubleshooting)

### 3.1 ⚠️ أول نشر للدوال (الجيل الثاني) يفشل جزئياً — الأكثر شيوعاً
رسائل مثل:
```
Permission denied while using the Eventarc Service Agent ...
Since this is your first time using 2nd gen functions, we need a little bit
longer to finish setting everything up. Retry the deployment in a few minutes.
Build failed ... missing permission on the build service account.
```
**السبب:** عند أول نشر، تُفعَّل خدمات Google جديدة (Eventarc, Cloud Build, Cloud Run, Artifact Registry) وتحتاج **حساباتها الخدمية بضع دقائق** لتنتشر صلاحياتها.

**الحل:**
1. **انتظر 3–5 دقائق.**
2. أعد المحاولة:
   ```bash
   firebase deploy --only functions
   ```
3. كرّر مرة أو مرتين إن لزم — تنجح الدوال تدريجياً.

### 3.2 سؤال سياسة حذف صور الحاويات
```
? How many days do you want to keep container images before they're deleted? (1)
```
أدخل رقماً صغيراً (مثلاً **`1`** أو `3`) واضغط Enter. هذا يحذف صور البناء القديمة تلقائياً لتقليل التكلفة. (آمن — لا يؤثّر على الدوال العاملة.)

### 3.3 إن استمر خطأ «build service account» بعد عدة محاولات
امنح حساب الخدمة الافتراضي دور Cloud Build (رقم المشروع: `868610876965`):
```bash
gcloud projects add-iam-policy-binding touba-3ds \
  --member="serviceAccount:868610876965-compute@developer.gserviceaccount.com" \
  --role="roles/cloudbuild.builds.builder"
```
أو من Console → IAM → ابحث عن `868610876965-compute@developer.gserviceaccount.com` → أضِف دور **Cloud Build Service Account** ثم أعد النشر.

### 3.4 تحذير firebase-functions «outdated» (غير حرج)
```
package.json indicates an outdated version of firebase-functions ...
```
اختياري للتحديث:
```bash
cd functions && npm install --save firebase-functions@latest && cd ..
```

### 3.5 تحذيرات npm vulnerabilities
ظهور «N vulnerabilities» عند `npm install` **غير حرج** لبيئة الدوال. **لا تشغّل** `npm audit fix --force` (قد يكسر الاعتماديات).

## 4. النشر المتكرر (بعد كل تعديل)
- بعد تعديل قواعد الأمان: `firebase deploy --only firestore:rules`
- بعد تعديل الفهارس: `firebase deploy --only firestore:indexes`
- بعد تعديل قواعد التخزين: `firebase deploy --only storage`
- بعد تعديل الدوال: `firebase deploy --only functions`
- نشر كل شيء دفعة واحدة: `firebase deploy`

---

## 5. التحقق بعد النشر
في [Firebase Console](https://console.firebase.google.com/project/touba-3ds/overview):
- **Firestore → Rules**: قواعد طوبة ظاهرة.
- **Firestore → Indexes**: الفهارس «Enabled».
- **Functions**: الدوال الخمس (`onMatchResultConfirmed`, `grantCapability`, `claimPlayerViaInvite`, `onJoinRequestAccepted`, `syncRosterSummary`) في منطقة `europe-west1`.
- **Storage → Rules**: قواعد طوبة ظاهرة.
