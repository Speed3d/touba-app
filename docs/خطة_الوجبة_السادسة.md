## القرارات المحسومة (من النقاش)
1. **الترتيب:** نبدأ بالمجموعة (أ) العاجلة وننشرها فوراً، ثم نتدرّج: أ → د → هـ → ب → ج.
2. **التشكيلة (بند 8):** **واحدة لكل بطولة** لكل فريق (أساسي/احتياط/خطة) + الكابتن يرسلها → **مراجعة المنظّم (قبول/رفض لكل فريق)** قبل البدء. + لاحقاً **تغيير الخطة لكل مباراة** (الكابتن يضغط كارت مباراته فيغيّر مثلاً 4-3-3 ← 4-4-2 عبر حقلَي `homeFormation/awayFormation`).
3. **التعيين على الملعب (بند 12):** يبقى الاشتقاق التلقائي **+ خيار** وضع كل لاعب بيده (ضغط دائرة → قائمة لاعبيه → اختيار) ويُحفظ التعيين الصريح. + خطة مخصّصة يصمّمها الكابتن.
4. **المؤقّت (بند 4ب):** **خادمي من `matchStartedAt`** (وقت بداية واحد مشترك، كل جهاز يحسب الفرق → موحّد ويصمد عند إغلاق التطبيق). **الأشواط يقودها المنظّم يدوياً** (بدأ شوط ١ → نهاية → بدأ شوط ٢ → نهاية → نتيجة). المدة (30/45) وعدد الأشواط (1/2) تُضبط عند إنشاء البطولة.
5. **التنقل (بند 9):** شريط سفلي **عائم** (نمط حرفي) بـ 4 أزرار، والبطولات+المباريات تنتقلان ككروت في الرئيسية، بتحكّم إظهار من لوحة الأدمن.
6. **فحص الاشتراك (بند 16):** **لحظي فقط** (مقارنة `expiresAt > now`) — **صفر تكلفة، دائماً دقيق، لا فحص مجدول**. حقل `status` يُحسب من `expiresAt`.

## المجموعة (د) — إعادة هيكلة التنقل والشاشات 🟢

### بند 9 — شريط تنقل سفلي عائم + كروت الرئيسية
- شريط **عائم** (نمط `app_bottom_navigation.dart` الحرفي) بـ **4 أزرار**: **الرئيسية / الفريق / المحادثات / الإعدادات**.
- **الرئيسية:** ترويسة (اسم + لوكو + جرس) كما هي · بانل الإعلانات كما هو · ثم **كارت الأخبار** (ضغط → شاشة الأخبار بصيغتها الحالية: صورة/عنوان/تفاصيل/إعجاب/مشاركة/مدة) · ثم **كارت البطولات** (ضغط → شاشة البطولات؛ **إظهاره يتحكّم به الأدمن** عبر `settings/features`) · ثم **كارت المباريات** (ضغط → شاشة المباريات بتصميمها الحالي).
- **الفريق:** كما هو (تبويبا فريقي/الفرق الشعبية).
- **المحادثات:** شاشة المحادثات (كابتن↔كابتن من التحدي، وكابتن↔لاعبيه لاحقاً).
- **الإعدادات:** كما هي (تعديلات كبيرة لاحقاً).
- يُزال تبويبا «البطولات» و«المباريات» من الشريط (انتقلا للرئيسية).

### بند 10 — شاشة الفريق (إعادة ترتيب)
- يبقى: اسم الفريق + الشعار الدائري + الاسم/المكان.
- كروت الإحصاء: **لعب · فاز · خسر · تعادل** (إضافة «تعادل» ليصحّ المجموع).
- زر «أنت لاعب» / «عرض وإدارة الفريق» (للكابتن) — كما هو.
- «التشكيلة» و«النقاط حسب البطولة» → **تبويبان** بدل التتالي.

### بند 11 — تبويب «فريقي» و«الفرق الشعبية»
- «فريقي»: إضافة **خسر + تعادل** للإحصاء · **حذف زر «محادثاتي»** (انتقل للشريط السفلي)، يبقى «تحدّيات الفرق» فقط.
- «الفرق الشعبية»: **فصل فريق الكابتن** — يُعرض «فريقي» أعلى (تحت البحث) ثم «فرق أخرى».

## المجموعة (ب) — المباراة الحيّة والجدولة 🟠

### بند 4ب — المباراة الحيّة + المؤقّت
- `MatchModel` ← دعم `status='live'` + `matchStartedAt` (timestamp) + `currentHalf` (int).
- على كل كارت مباراة (للمنظّم): زر **«بدأ المباراة»** بجانب تعديل الموعد/إدخال النتيجة → `status='live'`, `matchStartedAt=now`, `currentHalf=1`.
- تبويب **«جارية»** يعرض `status=='live'` (يراها الزائر/اللاعب/الكابتن: «مباراة الآن»).
- **المؤقّت:** كل جهاز يحسب `الدقيقة = now − matchStartedAt`. عند بلوغ المدة → «نهاية الشوط N».
- **الأشواط (منظّم):** «بدأ شوط ١» → عند المدة «نهاية الشوط الأول» → «بدأ شوط ٢» (`matchStartedAt=now, currentHalf=2`) → «نهاية» → «إدخال النتيجة» (`status='finished'`).
- إعدادات البطولة: `matchDuration` (دقائق/شوط: 30 أو 45) + `halvesCount` (1/2) عند الإنشاء.
- القواعد: حقول الحالة/المؤقّت يكتبها المنظّم (خارج جدار المصداقية — تعديل بسيط على قاعدة `matches` إن لزم).

### بند 5 — جدولة مرنة
عند الإنشاء: **توقيت ثابت يومي** + **عدد مباريات/يوم** (1/2/3) كلٌّ بوقت مختلف → التوليد التلقائي يوزّع المباريات (`FixturesService`) وفقها.

### بند 6 — تقرير PDF
زر «تصدير الجدول PDF» (للمنظّم) — جدول البطولة الكامل (المباريات/التواريخ/الأوقات) لمشاركته مع الكباتن. (مهارة `pdf`.)

### بند 7 — مركز اللاعب بجانب اسمه
في إدخال النتيجة وتفاصيل المباراة: «المهاجم - صلاح» / «الوسط - تحسين» (من `position`).

### بند 8 — تشكيلة البطولة + مراجعة المنظّم
- عند إنشاء البطولة وإضافة الفرق: **عرض اسم كابتن كل فريق** + **إشعار لكل كابتن** بإنشاء البطولة.
- الكابتن يُدخل **تشكيلة البطولة** (أساسيون + احتياط + خطة) **مرة واحدة** ويرسلها.
- **المنظّم يراجع** تشكيلة كل فريق → **قبول / رفض** قبل بدء البطولة.
- مجموعة جديدة مقترحة: `tournament_lineups/{tournamentId}_{teamId}` {starters[], subs[], formation, status: pending/approved/rejected, ...} + قواعد + إشعارات CF.

### بند 12 — تعيين تفاعلي + خطة مخصّصة
