## 1. المبادئ الحاكمة

1. **ترشيد الاستهلاك أولاً:** ضغط الصور + cache-first، تجميع مسبق للإحصائيات، ترقيم صفحات، بثّ حيّ فقط عند الحاجة، denormalization مدروس.
2. **الأمان من الخادم لا الواجهة:** كل قاعدة تُفرض في Security Rules / Cloud Functions. الواجهة للراحة فقط.
3. **سلامة الإحصائيات ذرّية:** كل تحديثات النتيجة داخل معاملة واحدة (كلها أو لا شيء) + idempotency + تراجع-ثم-تطبيق عند التعديل.
4. **مصدر حقيقة واحد:** لكل بيان مالك واحد يكتبه؛ البقية تقرأ. الإحصائيات يكتبها النظام (CF) حصراً.
5. **النموذج جاهز للمستقبل:** نحجز حقول المراحل القادمة (الحكّام، التصنيف، الرعاية) دون بنائها الآن.

## 3. نظام الأدوار والصلاحيات

نموذج **قائم على القدرات (Capabilities)**: دور أساسي واحد + صلاحيات إضافية يمنحها الأدمن.

### 3.1 الأدوار والصلاحيات
| القدرة | كيف تُكتسب | تُفرض عبر |
|---|---|---|
| `visitor` | بلا تسجيل | الواجهة |
| `user` (افتراضي) | بالتسجيل | `request.auth != null` |
| `captain` | بإنشاء فريق (أو اختيار الدور) | `team.captainId == uid` |
| `canCreateTournament` (منظّم) | يمنحها الأدمن | Custom Claim `organizer` + `adminPermissions` |
| `referee` (حكم) | يمنحها الأدمن | Custom Claim `referee` |
| `admin` / `superAdmin` | النظام | Custom Claim `admin`/`superAdmin` |

### 3.2 آلية المنح (إعادة استخدام نمط حرفي)
- الأدمن يمنح صلاحية من لوحة التحكم → تستدعي **Cloud Function `grantCapability`** (callable, admin-only) →
  - تضبط **Custom Claim** على حساب المستخدم (للفرض الأمني السريع في القواعد).
  - تحدّث `users.adminPermissions[]` (للعرض والإدارة).
- القواعد تتحقق من Custom Claims أولاً (سريع، لا قراءة Firestore)، مع fallback لـ `adminPermissions` عند الحاجة الانتقالية.

> **تعدّد الأدوار مسموح:** حساب واحد قد يكون كابتن + حكم. الحماية من التلاعب عبر **فصل المهام** و**حاجز تعارض المصالح** (انظر 7.4).

## 6. قواعد الأمان (Firestore Rules — مجموعات طوبة)

> تُضاف **فوق** قواعد المجموعات المشتركة. دوال مساعدة مفترضة: `isAuthenticated()`, `isOwner(uid)`, `isAdmin()`, و `isOrganizer()` = `request.auth.token.organizer == true`, و `isReferee()` = `request.auth.token.referee == true`.

```js
// ── الفرق ─────────────────────────────────────────────
match /teams/{teamId} {
  allow read: if true;                       // عام (صفحات الفرق)
  allow create: if isAuthenticated()
                && request.resource.data.captainId == request.auth.uid
                // منع تزوير الحقول المحسوبة عند الإنشاء
                && request.resource.data.ratingPoints == 1200
                && request.resource.data.stats.played == 0;
  allow update: if (isOwner(resource.data.captainId) || isAdmin())
                // الكابتن لا يلمس الحقول المحسوبة
                && (isAdmin() || !request.resource.data.diff(resource.data)
                     .affectedKeys().hasAny(['ratingPoints','stats','badges']));
  allow delete: if isOwner(resource.data.captainId) || isAdmin();
}

// ── اللاعبون ──────────────────────────────────────────
function isTeamCaptain(teamId) {
  return get(/databases/$(database)/documents/teams/$(teamId)).data.captainId == request.auth.uid;
}
match /players/{playerId} {
  allow read: if true;                       // عام (البطاقات)
  allow create: if isAuthenticated()
                && isTeamCaptain(request.resource.data.currentTeamId)
                && request.resource.data.careerStats.goals == 0; // لا تزوير
  allow update: if isAdmin()
                // الكابتن: حقول كروية، بلا careerStats
                || (isTeamCaptain(resource.data.currentTeamId)
                    && !request.resource.data.diff(resource.data)
                         .affectedKeys().hasAny(['careerStats','claimedByUid']))
                // اللاعب صاحب السجل: حقوله الشخصية فقط
                || (resource.data.claimedByUid == request.auth.uid
                    && request.resource.data.diff(resource.data).affectedKeys()
                         .hasOnly(['name','photoUrl','preferredFoot','height','weight','birthDate','updatedAt']));
  allow delete: if isAdmin() || isTeamCaptain(resource.data.currentTeamId);
}

// ── طلبات الانضمام ────────────────────────────────────
match /join_requests/{reqId} {
  allow read: if isAuthenticated() &&
              (resource.data.userId == request.auth.uid
               || isTeamCaptain(resource.data.teamId) || isAdmin());
  allow create: if isAuthenticated()
                && request.resource.data.userId == request.auth.uid
                && request.resource.data.status == 'pending';
  allow update: if isTeamCaptain(resource.data.teamId) || isAdmin(); // قبول/رفض
  allow delete: if isOwner(resource.data.userId) || isAdmin();
}

// ── روابط الدعوة (المطالبة تتم عبر CF) ────────────────
match /claim_invites/{inviteId} {
  allow read: if isAuthenticated();          // اللاعب يقرأ ليتحقق من الكود
  allow create: if isAuthenticated() && isTeamCaptain(request.resource.data.teamId);
  allow update, delete: if false;            // الاستخدام عبر Cloud Function فقط
}

// ── البطولات ──────────────────────────────────────────
match /tournaments/{tId} {
  allow read: if true;
  allow create: if isOrganizer() || isAdmin();
  allow update: if (resource.data.organizerUid == request.auth.uid || isAdmin())
                && (isAdmin() || !request.resource.data.diff(resource.data)
                     .affectedKeys().hasAny(['standings'])); // standings من CF
  allow delete: if resource.data.organizerUid == request.auth.uid || isAdmin();
}

// ── المباريات ─────────────────────────────────────────
function matchOrganizer(tournamentId) {
  return get(/databases/$(database)/documents/tournaments/$(tournamentId)).data.organizerUid == request.auth.uid;
}
match /matches/{matchId} {
  allow read: if true;
  allow create: if (isOrganizer() && matchOrganizer(request.resource.data.tournamentId)) || isAdmin();
  allow update: if (matchOrganizer(resource.data.tournamentId) || isAdmin())
                // العميل لا يلمس أعلام النظام
                && !request.resource.data.diff(resource.data)
                     .affectedKeys().hasAny(['statsApplied','appliedSnapshot']);
  allow delete: if matchOrganizer(resource.data.tournamentId) || isAdmin();
}

// ── صفحات الحكّام (م3) ────────────────────────────────
match /refereeProfiles/{uid} {
  allow read: if true;
  allow create, update: if (isOwner(uid) && isReferee()) || isAdmin();
  allow delete: if isAdmin();
}
```

> **جدار المصداقية:** `resultConfirmed` و `careerStats` و `stats` و `standings` و `ratingPoints` — **لا تُكتب من العميل**. النتيجة يؤكّدها المنظّم (تغيير `resultConfirmed`)، والباقي يحسبه CF.

## 7. قواعد Storage و 8. الفهارس و 9. الدوال السحابية

### 7. قواعد Storage (إضافة مسارات طوبة)
```js
// شعارات الفرق — الكابتن فقط
match /teams/{teamId}/logo/{fileName} {
  allow read: if true;
  allow write: if isAuthenticated() && isImage() && isValidSize()
               && firestore.get(/databases/(default)/documents/teams/$(teamId)).data.captainId == request.auth.uid;
}
// صور اللاعبين — الكابتن أو اللاعب صاحب السجل
match /players/{playerId}/photo/{fileName} {
  allow read: if true;
  allow write: if isAuthenticated() && isImage() && isValidSize();
}
// صور البروفايل — تصحيح المسار ليطابق التطبيق
match /users/{uid}/profile/{fileName} {
  allow read: if true;
  allow write: if isAuthenticated() && request.auth.uid == uid && isImage() && isValidSize();
}
// شعارات/صور البطولات — المنظّم
match /tournaments/{tId}/{fileName} {
  allow read: if true;
  allow write: if isAuthenticated() && isImage() && isValidSize();
}
```
> ⚠️ يجب توحيد مسار رفع صورة البروفايل في الكود (`users/{uid}/profile/...`) مع القاعدة، وتغيير مسار شعار الفريق إلى `teams/{teamId}/logo/...`.

### 8. الفهارس المركّبة المطلوبة
| المجموعة | الحقول | الغرض |
|---|---|---|
| `matches` | `dateTime ASC` | تبويب المباريات حسب التاريخ (كل البطولات) |
| `matches` | `tournamentId ASC, round ASC` | مباريات بطولة مرتّبة بالجولات |
| `matches` | `tournamentId ASC, status ASC, dateTime ASC` | مباريات/نتائج بطولة |
| `matches` | `homeTeamId ASC, dateTime DESC` + `awayTeamId ASC, dateTime DESC` | مباريات فريق |
| `teams` | `city ASC, ratingPoints DESC` | أفضل فرق المدينة |
| `teams` | `nameLower ASC` | بحث/كشف تكرار |
| `players` | `currentTeamId ASC, shirtNumber ASC` | تشكيلة الفريق |
| `players` | `claimedByUid ASC` | ربط الحساب بسجله |
| `tournaments` | `status ASC, startDate DESC` | بطولات جارية/قادمة |
| `join_requests` | `teamId ASC, status ASC` | طلبات فريق معيّن |

### 9. الدوال السحابية (Cloud Functions — صياغة v2 + region `europe-west1`)
| الدالة | المُشغّل | المنطق |
|---|---|---|
| `onMatchResultConfirmed` | `onDocumentUpdated('matches/{id}')` | عند `resultConfirmed: false→true`: **معاملة ذرّية** تحدّث stats الفريقين + ratingPoints + standings البطولة + careerStats للاعبين (من `events`). تضبط `statsApplied=true` وتخزّن `appliedSnapshot`. **Idempotent** (تتجاهل إن `statsApplied`). **تراجع-ثم-تطبيق** عند تعديل نتيجة مؤكّدة. |
| `grantCapability` | callable (admin) | يضبط Custom Claim (`organizer`/`referee`/`admin`) + يحدّث `adminPermissions[]`. |
| `claimPlayerViaInvite` | callable | يتحقق من `token` صالح/غير منتهٍ → يربط `players.claimedByUid` و `users.linkedPlayerId` ذرّياً → يضع الدعوة `used`. |
| `onJoinRequestAccepted` | `onDocumentUpdated('join_requests/{id}')` | عند القبول: ينشئ/يربط سجل لاعب + يضيفه لـ `roster` ذرّياً. |
| `syncRosterSummary` | `onDocumentWritten('players/{id}')` | يزامن ملخّص `teams.roster` عند تغيّر اسم/صورة/مركز اللاعب. |
| (م3) `aggregateRefereeRating` | عند تقييم حكم | يجمّع `refereeProfiles.rating` و `matchesCount`. |

## 10. الخوارزميات الأساسية

- **توليد جدول الدوري (Round-Robin / Circle Method):** تثبيت فريق وتدوير البقية؛ لعدد فردي يُضاف فريق وهمي (Bye). عدد المباريات = n×(n−1)/2 (ذهاب فقط) ×2 للإياب. تُنفَّذ عند تثبيت فرق البطولة (يدوياً عبر زر «توليد الجدول» أو CF).
- **حساب الترتيب:** بعد كل نتيجة مؤكّدة، تُحدَّث `standings` وتُرتَّب: النقاط ← فارق الأهداف ← الأهداف المسجّلة ← المواجهة المباشرة (حسب `tiebreakers`).
- **التصنيف العام (ratingPoints):** نموذج بسيط قابل للضبط في الـ MVP (1200 أساس). نموذج Elo مؤجَّل (القرار 3 بالخطة: يُقرَّر لاحقاً). **منفصل تماماً** عن نقاط ترتيب البطولة.
- **تجميع الإحصائيات (Pre-aggregation):** عدّادات جاهزة على مستندات اللاعب/الفريق/البطولة تُزاد داخل معاملة النتيجة → قراءة فورية رخيصة.

## 11. التدفقات الأساسية (Sequences)

1. **إنشاء فريق:** كابتن → `teams.create` (rules: captainId==uid) → رفع الشعار (Storage) → `users.role='captain'`.
2. **إضافة لاعب مباشرة:** الكابتن → `players.create` (currentTeamId لفريقه) → CF `syncRoster` يحدّث `roster`.
3. **دعوة لاعب للمطالبة:** الكابتن → `claim_invites.create` → يرسل الرابط → اللاعب يفتح/يسجّل → callable `claimPlayerViaInvite` → ربط ذرّي.
4. **طلب انضمام:** لاعب لديه حساب → `join_requests.create` → الكابتن يقبل → CF `onJoinRequestAccepted` ينشئ/يربط سجل لاعب.
5. **إنشاء بطولة:** منظّم (صلاحية) → `tournaments.create` → اختيار الفرق → «توليد الجدول» → `matches.create` (عدة).
6. **إدخال نتيجة:** المنظّم → تحديث `matches` (score/events) → `resultConfirmed=true` → CF `onMatchResultConfirmed` يحدّث كل شيء ذرّياً.

## 12. استراتيجية ترشيد الاستهلاك (تطبيقياً)

- **الصور:** `flutter_image_compress` قبل الرفع (حد ≤ ~300KB) + `cached_network_image` (cache-first) → تحميل مرة وقراءة من الكاش.
- **القوائم:** `limit()` + ترقيم صفحات (startAfter) على الفرق/البطولات/المباريات. لا `get()` لمجموعة كاملة أبداً.
- **التشكيلة:** تُقرأ من `teams.roster` (قراءة مستند واحد) بدل قراءة كل لاعب؛ سجل اللاعب الكامل يُقرأ فقط عند فتح البطاقة.
- **البثّ الحيّ (`snapshots`)** فقط لشاشة المباراة الجارية والترتيب أثناء البطولة؛ بقية الشاشات `get()` مع كاش محلي (hive/shared_preferences) عند الحاجة.
- **التجميع المسبق:** القوائم (هدّافون، ترتيب) تُقرأ من حقول جاهزة لا تُحسب لحظياً.
