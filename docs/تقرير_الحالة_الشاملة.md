## 3) 🔴 مشاكل مؤكَّدة (محقّقة بالفحص)

### 3.1 الكردية: اتجاه النص وودجات Material
`flutter_localizations` **لا يدعم `ku`** (تحقّق مباشر من Flutter SDK: `MaterialLocalizationKu` غير موجودة، و`ku` ليست في قائمة اللغات المدعومة). ولا يوجد delegate مخصّص ولا `localeResolutionCallback` في `main.dart`.

**الأثر:** (1) الكردية تُعرض **LTR** بينما السوراني يُكتب بالخط العربي ويحتاج **RTL** → التخطيط ينقلب. (2) ودجات Material المدمجة (منتقي التاريخ/الوقت، قائمة تحديد النص) بلا ترجمة، واحتمال خطأ «No MaterialLocalizations found».

**الحل المعياري:** delegates مخصّصة لـ `ku` تُحمّل موارد `ar` (نفس الخط والاتجاه) لـ `MaterialLocalizations` و`WidgetsLocalizations` و`CupertinoLocalizations`.

### 3.2 الويب لا يعمل إطلاقاً
`lib/firebase_options.dart` يحوي **`android` و`ios` فقط** — لا فرع `web`. عند التشغيل على Chrome يرمي `Firebase.initializeApp` استثناءً فوراً. (مجلد `web/` مُهيّأ لكن بلا إعداد Firebase.)

### 3.3 ملفات حرجة لن تصل للجهاز الثاني
| الملف | الحالة | الأثر على الماك |
|---|---|---|
| `firebase.json` | 🔴 غير متعقّب | لا نشر من الماك |
| `.firebaserc` | 🔴 غير متعقّب | لا يعرف المشروع الهدف |
| `android/app/google-services.json` | 🔴 مُستثنى بـ `.gitignore` | **بناء أندرويد يفشل** |
| `ios/Runner/GoogleService-Info.plist` | 🔴 مُستثنى بـ `.gitignore` | **بناء iOS يفشل** |
| `craftsman_backup/` | 🔴 مستودع git مضمّن (gitlink) بلا `.gitmodules` | **يصل كمجلد فارغ** |

> ✅ في المقابل، الأسرار محميّة بشكل صحيح: `touba_release.jks` و`key.properties` و`local.properties` **غير متعقّبة** (وهذا هو الصواب).

### 3.4 إعداد VS Code
- `.vscode/settings.json` **خاطئ**: يشير إلى مسار مشروع آخر (`.../empty/test_app/linux`) وخاص بويندوز.
- **لا يوجد `.vscode/launch.json`** — بينما «حرفي العراق» يملك واحداً ناضجاً (منفذ ويب 5000 لويندوز / 5001 للماك تفادياً لتصادم AirPlay).
