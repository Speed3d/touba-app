# 🍎 دليل الإعداد على الماك — طوبة

> **الجهاز المستهدف:** MacBook Air **M5** (Apple Silicon) · **المحرّر:** VS Code
> **الهدف:** تشغيل طوبة على **محاكي iPhone** و**محاكي أندرويد** من الماك، بنفس تجربة ويندوز.
> **ملاحظة:** أُعِدّ هذا الدليل من ويندوز — **لم يُختبر على الماك بعد**. نفّذه وأخبرني بأي خطأ فأصلحه.

---

## 0) قبل البدء — ما يصل مع Git وما لا يصل

| يصل مع `git pull` ✅ | **لا** يصل — نقل يدوي 🔴 |
|---|---|
| كل كود `lib/` و`functions/` | `android/app/google-services.json` |
| `firestore.rules` · `storage.rules` · `firestore.indexes.json` | `ios/Runner/GoogleService-Info.plist` |
| `pubspec.yaml` + `pubspec.lock` | `firebase.json` · `.firebaserc` |
| `ios/Podfile` + `Podfile.lock` | `android/app/touba_release.jks` (للإصدار فقط) |
| `.vscode/` (تشغيل ومهام) | `android/key.properties` (للإصدار فقط) |
| `craftsman_backup` (submodule) | `android/local.properties` (يُولَّد تلقائياً) |

> المالك ذكر أنه **نقل ملفات Firebase سابقاً وأكمل الإعدادات على الماك** — لذا ابدأ بقائمة التحقّق في القسم 5.

## 1) الأدوات الأساسية

### 1.1 Xcode (لـ iOS)
```bash
xcode-select --install                       # أدوات سطر الأوامر
sudo xcodebuild -license accept              # قبول الرخصة
sudo xcode-select -s /Applications/Xcode.app/Contents/Developer
xcodebuild -runFirstLaunch
```
ثبّت **Xcode** من App Store، ثم من داخله:
`Settings → Components` → نزّل **iOS Simulator**.

### 1.2 CocoaPods (على Apple Silicon)
```bash
brew install cocoapods        # الأفضل على M-series (أنظف من gem)
pod --version
```

### 1.3 Flutter SDK
```bash
brew install --cask flutter   # أو التنزيل اليدوي من flutter.dev
flutter --version
```

### 1.4 أندرويد
ثبّت **Android Studio** → من `SDK Manager`:
- Android SDK Platform (أحدث)
- Android SDK Command-line Tools
- Android SDK Build-Tools
- **Android Emulator** + صورة نظام (يُفضّل **arm64-v8a** على M-series)

ثم:
```bash
flutter doctor --android-licenses    # اقبل كل الرخص
```

### 1.5 التحقّق الشامل
```bash
flutter doctor -v
```
> يجب أن تكون كل البنود ✅ عدا ما لا تحتاجه (مثل Chrome إن أجّلنا الويب).

## 2) جلب المشروع

```bash
git clone https://github.com/Speed3d/touba-app.git
cd touba-app

# 🔴 مهم: craftsman_backup مستودع فرعي (submodule) — لا يأتي مع clone وحده
git submodule update --init --recursive

flutter pub get
```

### تحقّق أن المرجع وصل
```bash
ls craftsman_backup/lib | head
```
إن كان المجلد فارغاً، أعِد:
```bash
git submodule update --init --recursive
```

> ⛔ **`craftsman_backup` مرجع للقراءة فقط** — يُمنع التعديل أو الإضافة أو الحذف داخله.

## 3) ملفات Firebase (النقل اليدوي)

انسخ من ويندوز إلى نفس المسارات على الماك:

| من ويندوز | إلى الماك |
|---|---|
| `android/app/google-services.json` | `android/app/google-services.json` |
| `ios/Runner/GoogleService-Info.plist` | `ios/Runner/GoogleService-Info.plist` |
| `firebase.json` | `firebase.json` |
| `.firebaserc` | `.firebaserc` |

### تحقّق من ربط Firebase CLI
```bash
npm install -g firebase-tools     # إن لم يكن مثبّتاً
firebase login
firebase use touba-3ds
firebase projects:list
```

> ⚠️ **`GoogleService-Info.plist` لا يكفي نسخه** — يجب أن يكون مُضافاً لهدف Runner داخل Xcode.
> افتح `ios/Runner.xcworkspace` وتأكد أن الملف يظهر ضمن `Runner` و`Target Membership` مفعّل.

## 5) ✅ قائمة التحقّق (نفّذها في أول جلسة على الماك)

| # | التحقّق | الأمر | النتيجة المتوقّعة |
|---|---|---|---|
| 1 | ملف أندرويد موجود | `ls android/app/google-services.json` | يظهر المسار |
| 2 | ملف iOS موجود | `ls ios/Runner/GoogleService-Info.plist` | يظهر المسار |
| 3 | إعداد Firebase موجود | `ls firebase.json .firebaserc` | يظهران |

| 9 | بناء iOS | `flutter build ios --debug --no-codesign` | ينجح |

> إن فشل أيّ بند: **انسخ نصّ الخطأ كاملاً وأرسله لي** — أصلحه فوراً.

## 6) التشغيل من VS Code

المشروع فيه `.vscode/launch.json` جاهز يعمل على النظامين.

1. افتح المجلد في VS Code.
2. اختر الجهاز من **شريط الحالة السفلي** (محاكي iPhone / محاكي أندرويد).
3. اضغط **F5** → إعداد **«طوبة (الجهاز المختار)»**.

### تشغيل المحاكيات
```bash
open -a Simulator          # محاكي iPhone
flutter emulators          # عرض محاكيات أندرويد
flutter emulators --launch <emulator_id>
flutter devices            # التأكد من الأجهزة المتاحة
```

### المهام السريعة
`Cmd+Shift+P` → **Run Task** → (pub get · analyze · test · gen-l10n · نشر · submodule · doctor).

## 8) مشاكل شائعة على Apple Silicon

| المشكلة | الحل |
|---|---|
| `pod install` يفشل بخطأ معماريّة | `arch -x86_64 pod install` أو `brew install cocoapods` بدل gem |
| `CocoaPods not installed` | `brew install cocoapods` ثم `pod setup` |
| المحاكي بطيء جداً | استخدم صورة **arm64-v8a** لا x86 |
| `Unable to find Xcode` | `sudo xcode-select -s /Applications/Xcode.app/Contents/Developer` |
| `flutter build ios` يطلب توقيعاً | أضف `--no-codesign` للتجربة، أو اضبط فريق التوقيع في Xcode |
| تعارضات ملفات كاملة في git | `.gitattributes` يعالجها؛ إن ظهرت: `git add --renormalize .` |
| `Podfile.lock` يتعارض | خذ نسخة الريموت ثم `pod install` |

## 9) الويب — مؤجّل

`lib/firebase_options.dart` يحوي `android` و`ios` فقط (بلا `web`) → **التشغيل على Chrome سيفشل**.
إعدادات الويب في `launch.json` موسومة **[مؤجّل]**. عند تفعيله لاحقاً: `flutterfire configure` + إضافة منصّة web.
